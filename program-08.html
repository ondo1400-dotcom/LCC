About This Program

"나는 원래 이런 건 못해"라는 문장은 대부분 검증된 적이 없습니다. 이 프로그램은 스스로 정의한 한계를 하나씩 꺼내어 정말인지 실험해 보는 도전 워크숍이었습니다.

참가자들은 자신의 한계 목록을 만들고, 그중 하나를 골라 현장에서 바로 작게 시도해 보며 한계의 상당수가 경험 부족일 뿐임을 확인했습니다.

Program Flow

  • Error — 나의 한계 목록 작성 · 근거 검증하기
  • Debug — 한계 하나 골라 현장에서 실험
  • Reload — 결과 회고 · 한계 다시 정의하기

What You Take Away

  • 검증을 거친 진짜 나의 현재 좌표
  • 한계를 실험으로 바꾸는 사고 습관
  • 작은 성공의 즉각적인 경험
