Privacy Policy

개인정보 처리방침.

Life Code Company는 멘티가 우리에게 맡기는 정보를, 멘티가 자신에게 맡기는 마음과 같은 무게로 다룹니다. 이 문서는 우리가 그 약속을 지키는 방식을 정리한 것입니다.

1. 우리의 약속

Life Code Company는 라이프 컨설팅과 멘토링이라는 서비스의 본질이 신뢰 위에 세워진다는 점을 항상 기억합니다. 멘티가 우리에게 남기는 한 줄의 문장과 한 번의 클릭은, 한 사람의 인생의 결을 담은 정보입니다. 본 방침은 「개인정보 보호법」 등 관련 법령을 준수하는 한편, 법이 요구하는 최소선이 아닌 Life Code Company가 스스로에게 약속하는 ‘우리가 멘티라면 어떻게 다뤄지길 바라는가’의 기준으로 만들었습니다.

2. 수집하는 개인정보 항목

Life Code Company는 다음의 정보를 멘티의 동의에 기반하여 수집합니다.

가. 필수 항목

  • 이름, 이메일 주소
  • 문의 유형 및 문의 내용
  • 홈페이지 접속 로그(IP, 접속 시간 등 자동 생성 정보)

나. 선택 항목 (멘토링·워크숍 신청 시)

  • 휴대전화 번호, 소속(회사·학교·단체)
  • 관심 트랙(Career · Self-Growth · Research · Creative 등)
  • 진단 세션에서 멘티가 자발적으로 공유한 자기 분석 정보

Life Code Company는 주민등록번호, 금융정보, 민감정보(사상·신념·정치적 견해·의료 기록 등)를 수집하지 않습니다. 멘토링 과정에서 멘티가 자발적으로 언급하더라도, Life Code Company는 해당 정보를 별도 데이터베이스에 저장하지 않으며, 세션 종료 후에는 멘토의 메모 형태로만 제한적으로 활용됩니다.

3. 개인정보 수집·이용 목적

  • 상담 응답 — 무료 진단 상담의 일정 조율 및 답변
  • 서비스 제공 — 멘토 매칭, 프로그램 운영, 세션 진행, 분기 회고 발송
  • 품질 개선 — 만족도 조사, 멘토링 방법론 갱신
  • 법적 의무 이행 — 분쟁 발생 시 사실 확인 및 관련 법령 준수

수집된 정보는 위 목적 외의 용도로는 사용되지 않으며, 목적이 변경될 경우 사전 동의를 다시 요청합니다.

4. 보유 및 이용 기간

Life Code Company는 수집한 개인정보를 다음 기간 동안만 보유하며, 그 이후에는 안전하게 파기합니다.

  • 단순 문의자: 답변 완료 후 6개월
  • 멘토링·워크숍 수료자: 마지막 세션일로부터 3년 (관련 법령상의 보존 의무 및 사후 회고·환불 분쟁 대비)
  • 접속 로그: 3개월 (정보통신망법에 따른 최소 보존)

멘티가 보유 기간 종료 전에 삭제를 요청하면, 법령상 의무 보존이 필요한 항목을 제외하고 지체 없이 파기합니다.

파기 절차 및 방법 — 보유 기간이 경과하거나 처리 목적이 달성된 개인정보는 내부 방침에 따라 지체 없이 파기합니다. 전자적 파일 형태의 정보는 복구·재생이 불가능한 기술적 방법으로 영구 삭제하며, 종이에 출력된 정보는 분쇄하거나 소각하여 파기합니다.

5. 제3자 제공

Life Code Company는 멘티의 개인정보를 제3자에게 제공하거나 판매하지 않습니다. 단, 다음의 경우에 한해 예외적으로 제공될 수 있습니다.

  • 멘티가 사전에 동의한 경우
  • 법령에 근거한 수사기관의 요청이 있는 경우

6. 처리 위탁

원활한 서비스 운영을 위해 일부 처리 업무를 외부에 위탁할 수 있습니다. 모든 수탁자는 개인정보 보호 의무를 Life Code Company와 동일하게 부담합니다.

  • 이메일·문서 인프라: Google Workspace
  • 화상 멘토링 세션: Zoom / Google Meet
  • 일정 관리: Google Calendar

개인정보의 국외 이전 — 위 수탁자 중 일부(Google, Zoom 등)는 글로벌 클라우드 서비스로, 개인정보가 미국 등 국외 서버에서 처리·보관될 수 있습니다. 해당 사업자들은 개인정보 보호를 위한 국제 표준 및 관련 법령을 준수하며, Life Code Company는 서비스 제공에 필요한 최소한의 정보만을 위탁합니다. 국외 이전을 원하지 않으실 경우 lifecodecompany.korea@gmail.com으로 문의해 주시면 대체 방안을 안내해 드립니다.

7. 정보주체의 권리

멘티는 언제든 Life Code Company에 다음의 권리를 행사할 수 있습니다. 모든 요청은 7영업일 이내에 처리됩니다.

  • 개인정보 열람 청구
  • 오류 등이 있을 경우 정정·삭제 청구
  • 처리 정지 청구
  • 수집·이용 동의의 철회

권리 행사는 lifecodecompany.korea@gmail.com으로 이메일을 보내주시면 본인 확인 후 처리해 드립니다.

8. 안전성 확보 조치

  • 관리적 조치 — 개인정보 접근 권한자 최소화, 정기 내부 교육
  • 기술적 조치 — 저장·전송 시 암호화, 비인가 접근 차단
  • 물리적 조치 — 보안이 적용된 클라우드 환경에서만 저장
Life Code Company는 ‘완벽한 보안’이라는 말이 환상임을 알기에, ‘최선의 보안’과 ‘투명한 대응’을 함께 약속합니다. 만약 정보 침해가 발생할 경우, 멘티에게 가장 먼저 알리고, 무엇이 일어났는지를 있는 그대로 공유합니다.

9. 쿠키 및 자동 수집 도구

Life Code Company 홈페이지는 사용성 개선을 위한 최소한의 쿠키만 사용합니다. 브라우저 설정을 통해 언제든 쿠키 저장을 거부할 수 있으며, 거부 시 일부 기능 사용에 제한이 있을 수 있습니다. 광고 추적 목적의 제3자 쿠키는 사용하지 않습니다.
