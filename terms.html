이용 약관.

약관은 멘티를 보호하는 문장이자, Life Code Company가 스스로에게 거는 약속입니다. 신뢰는 명문화에서 시작됩니다.

Terms 최종 개정 2026.05.01 시행 2026.05.01

제1조 (목적)

본 약관은 Life Code Company가 제공하는 라이프 컨설팅, 멘토링, 워크숍, 키노트, 글로벌 익스체인지 등 일체의 서비스(이하 "서비스")의 이용 조건과 절차, Life Code Company와 이용자(이하 "멘티") 간의 권리·의무·책임 사항을 규정함을 목적으로 합니다.

제2조 (용어의 정의)

  • "서비스"란 Life Code Company가 멘티에게 제공하는 모든 컨설팅·멘토링·교육 활동을 말합니다.
  • "멘티"란 본 약관에 동의하고 서비스를 신청·이용하는 개인 또는 단체를 말합니다.
  • "멘토"란 Life Code Company가 정한 검증 기준을 통과하여 서비스 제공에 참여하는 전문가를 말합니다.
  • "세션"이란 멘티와 멘토가 일정에 따라 진행하는 1회의 만남(온라인·오프라인 포함)을 말합니다.

제3조 (약관의 효력과 변경)

본 약관은 멘티가 서비스 신청 시 동의함으로써 효력이 발생합니다. Life Code Company는 합리적인 사유가 있을 경우 약관을 변경할 수 있으며, 변경 시에는 시행일 7일 전 홈페이지 및 이메일을 통해 사전 고지합니다. 멘티에게 불리한 변경의 경우, 명시적 재동의 절차를 거칩니다.

제4조 (서비스의 제공)

Life Code Company가 제공하는 서비스는 다음을 포함하되 이에 한정되지 않습니다.

  • 1:1 Mentoring (12주 풀 사이클 · Career / Startup / Research / Creative 트랙)
  • Group Workshop (2일 / 14시간 · 6–12명)
  • Keynote & Lecture (45분–4시간 · 50–500명)
  • Global Exchange (2주 · 5개국 거점 순환)
  • 무료 진단 상담(30분)

Life Code Company는 서비스의 품질을 유지하기 위해 멘토 매칭, 프로그램 모듈, 운영 방식 등을 사전 고지 후 변경할 수 있습니다.

제5조 (신청과 매칭)

멘티는 홈페이지의 문의 폼, 이메일, 또는 Life Code Company가 지정한 경로를 통해 서비스를 신청할 수 있습니다. 신청 접수 후 Life Code Company는 24시간 이내(영업일 기준)에 회신하며, 무료 진단 상담을 통해 가장 적합한 프로그램과 멘토를 함께 결정합니다.

멘티는 진단 결과에 동의하지 않거나 매칭된 멘토가 적합하지 않다고 판단되는 경우, 매칭 변경을 1회 무상 요청할 수 있습니다.

제6조 (결제와 환불)

모든 유료 서비스의 비용은 사전 상담·협의 과정에서 안내되며, 결제는 홈페이지를 통한 자동결제가 아닌 개별 안내(계좌이체 등)에 따라 별도로 진행됩니다. 별도 협의가 없는 한 결제는 첫 세션 전에 완료되어야 합니다.

환불 정책

  • 첫 세션 시작 전: 전액 환불
  • 첫 세션 후 7일 이내: 진행분 차감 후 부분 환불
  • 7일 경과 후: 잔여 회차에 따른 비례 환불 (개별 약정 우선)

환불 요청은 lifecodecompany.korea@gmail.com을 통해 접수되며, 영업일 기준 7일 이내 처리됩니다. Life Code Company는 환불의 사유를 따져 묻지 않으며, ‘맞지 않는다’는 한 줄의 답도 충분히 존중합니다.

제7조 (멘티의 책임)

멘토링은 멘티의 적극적인 참여 위에서 의미를 갖는 서비스입니다. 멘티는 다음을 약속합니다.

  • 세션 시간을 성실히 지키고, 부득이한 변경 시 최소 24시간 전 통지
  • 자기 분석 과제와 회고 작성에 가능한 한 정직하게 임할 것
  • 세션 중 공유된 동료 멘티의 정보를 외부에 누설하지 않을 것
  • Life Code Company 자료(워크북·템플릿·녹화본 등)를 외부에 무단 배포하지 않을 것

제8조 (Life Code Company의 약속)

Life Code Company는 본 약관과 별개로, 멘티에게 다음을 약속합니다.

  • 비밀 유지 — 세션에서 공유된 멘티의 어떤 정보도 본인 동의 없이 외부에 공개하지 않습니다.
  • 응답의 품질 — 모든 문의에 24시간 이내 답변하며, 답변이 늦어질 경우 사유를 명시합니다.
  • 결과에 대한 윤리 — 멘티의 성과나 변화 사례를 마케팅에 활용할 때는 반드시 사전 동의를 받습니다.
  • 중단의 예고 — 서비스 운영을 중단할 경우 최소 30일 전 사전 고지합니다.
“정답을 주는 회사가 아닌, 스스로 답에 닿게 돕는 파트너.” 약관에서도 우리의 자세는 같습니다. 멘티의 결정과 시간을 존중하고, Life Code Company는 그 결정이 가장 좋은 결정이 되도록 돕는 환경과 도구를 제공할 뿐입니다.

제9조 (지적재산권)

Life Code Company가 제작·제공하는 워크북, 진단 도구, 프레임워크(예: L.I.F.E Method), 강의 자료, 영상, 템플릿 등 모든 자료의 저작권은 Life Code Company에 귀속됩니다. 멘티는 개인 학습 목적으로만 자료를 활용할 수 있으며, 영리적 재배포·복제·재가공은 사전 서면 동의 없이 금지됩니다.

반대로, 멘티가 세션 중 작성한 개인의 자기 분석 결과물 및 회고문은 멘티의 소유이며, Life Code Company는 이를 멘티의 명시적 동의 없이 어떠한 형태로도 외부에 활용하지 않습니다.

제10조 (책임의 제한)

Life Code Company는 멘토링·컨설팅의 결과로서 멘티의 인생 결정에 대한 법적 책임을 지지 않습니다. 모든 결정과 실행의 주체는 멘티 자신입니다. 다만 Life Code Company가 본 약관에 명시된 의무를 다하지 못해 멘티에게 직접적이고 명확한 손해가 발생한 경우, Life Code Company는 그에 상응하는 책임을 부담합니다.

Life Code Company는 천재지변, 통신 장애, 멘토의 불가피한 사정 등 Life Code Company의 합리적 통제를 벗어난 사유로 세션이 지연·취소되는 경우 즉시 멘티에게 알리고 대체 일정을 협의합니다.

제11조 (분쟁 해결)

Life Code Company와 멘티 사이에 분쟁이 발생할 경우, 양 당사자는 신의성실 원칙에 따라 우선 협의를 통해 해결하도록 노력합니다. 협의가 성립되지 않을 경우, 본 약관은 대한민국 법률의 적용을 받으며, 관할 법원은 서울중앙지방법원으로 합니다. 글로벌 거점에서 체결된 별도 약정이 있는 경우 해당 약정의 준거법이 우선합니다.
