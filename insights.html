Life Code Company를 만난 사람들의 이야기

실제 참가자의 경험을 재구성한 이야기이며, 개인의 상황에 따라 결과는 다를 수 있습니다.

Career 2025 · 1:1 Mentoring

휴학을 결심하고도 진로가 보이지 않아 Life Code Company를 찾았습니다. 사실 처음엔 또 하나의 자기계발 컨설팅이겠지 싶었어요. 그런데 첫 진단 세션부터 달랐습니다. 제가 어떤 가치를 따라왔는지, 어떤 패턴에 갇혀 있는지를 데이터로 보여주시는데, 너무 정확해서 한참을 멍하니 있었던 기억이 나요. 12주 멘토링을 마치고 나니, ‘정답을 찾았다’가 아니라 ‘저만의 질문을 갖게 됐다’는 느낌이에요. 지금은 휴학 1년을 가장 의미 있게 보내고 있습니다. 비교가 아닌 저만의 속도, 그게 Life Code Company가 제게 남긴 가장 큰 선물이에요.

Y
대학생 YCareer Track 수료생

33살에 처음으로 ‘나는 누구인가’라는 질문을 진지하게 한 것 같아요. 일은 잘하고 있는데, 마음이 늘 비교에 시달렸거든요. SNS만 봐도 위축되고, 친구의 성공조차 축하하기 힘든 제 자신이 부끄러웠어요. Life Code Company의 자기 분석 워크숍에서 처음 마주한 건, 제가 ‘비교하지 말자’고 다짐만 해왔지 정작 비교의 패턴을 한 번도 들여다본 적이 없었다는 사실이었습니다. 멘토님은 답을 주지 않으셨어요. 대신 제가 답에 닿을 수 있는 질문들을 정확히 던져주셨습니다. 6개월이 지난 지금, 저는 처음으로 제 자신을 응원할 줄 아는 사람이 되었어요.

Life Code Company에서는 제 사업이 아닌 저라는 사람부터 분석했습니다. ‘왜 이 일을 시작했는가, 무엇이 진짜 자신의 언어인가.’ 그 답이 정리되니 마케팅 카피가 5분 만에 새로 쓰여졌어요. 그 카피로 다음 분기 매출에도 눈에 띄는 변화가 있었습니다. 컨설팅이 비즈니스 결과로 이어지는 경험은 처음이었어요. 사업가에게 가장 필요한 컨설팅은 결국 ‘자기 자신’에 대한 컨설팅이라는 걸 Life Code Company를 통해 배웠습니다.

Life Code Company가 없었다면 시작도 못했을 거예요.

Life Code Company의 Research Track 멘토님은 학문적 조언이 아닌 ‘연구자라는 정체성’에 대한 대화를 먼저 나눠주셨어요. 제가 왜 이 주제를 선택했는지, 무엇이 두려운지, 어떤 연구자가 되고 싶은지. 6개월의 멘토링이 끝날 무렵, 저는 다시 논문을 쓸 수 있는 사람이 되어 있었습니다. 지금은 학회 발표를 앞두고 있고, 무엇보다 ‘내 연구가 가치 있다’고 말할 수 있게 됐어요. Life Code Company는 제게 연구 방법을 가르친 것이 아니라, 연구하는 저를 다시 일으켜 세웠습니다.

Life Code Company의 도구들은 제가 저를 다시 들여다보게 해줬습니다. 지금은 ‘느려도 나의 속도’라는 말을 진심으로 할 수 있어요. 무리하지 않아도 멀리 갈 수 있다는 걸, 처음으로 믿게 됐습니다. 인생에서 가장 잘한 결정 중 하나가 Life Code Company의 워크숍을 신청한 거였어요.
